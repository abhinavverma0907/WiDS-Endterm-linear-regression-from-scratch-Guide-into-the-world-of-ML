# Developing Linear Regression Algorithm from Beginning (Single Predictor)

## Overview of the Project
This project aims to develop a linear regression algorithm with only a single predictor variable with Python programming using no libraries such as scikit-learn or any other library which is related to machine learning.

## Software Used
- NumPy
- Pandas
- Matplotlib

## Compliance With Restrictions
- No use of the scikit-learn Library.
- No use of TensorFlow and PyTorch.
- All of the code has been written by the developer.

## Data Used
Contains two sets of data:
- The independent variable X
- The dependent variable Y

## Information on the Linear Regression Algorithm
Using the following equation:
y = mx + b

The loss function initially chosen is:
Mean Squared Error (MSE)

The optimization function that was used was:
Gradient Descent

## Steps For Running It
1. To install the package necessary to use the training script:
pip install -r requirements.txt

2. Run the training script:
python src/train.py

## Final Products
- The learned slope and intercept for the regression line.
- The regression line is plotted on top of the actual training data.
